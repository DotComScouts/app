TRANSPARENT & NACHVOLLZIEHBAR

So arbeitet die Suche

01Neue Signale finden

Je nach Suchmodus werden Hacker-News-Beiträge, ergänzende Hacker-News-Suchtreffer und neue GitHub-Softwareprojekte ausgewertet.

02Namen bewerten

Aktualität, Resonanz und Signale aus mehreren Quellen werden stärker gewichtet als ein einzelner Fund. Eine automatisierte Vorprüfung markiert mögliche sprachliche Risiken in Deutsch, Englisch, Französisch und Spanisch – sie ersetzt keine gründliche Sprach- oder Markenprüfung.

03.com prüfen

Die .com-Verfügbarkeit wird live abgefragt und kann sich jederzeit ändern. Vor einer Registrierung erneut prüfen und Marken- sowie Namensrechte separat recherchieren. Ein freier Name ist weder eine Nachfrageprognose noch eine Garantie für Wiederverkaufswert.

Die Suche deckt nicht das gesamte Internet ab. Trendwerte sind interne Orientierungshilfen, keine objektiven Marktprognosen. Originalnamen ohne ausreichende Bestätigung werden nicht als Kaufkandidaten priorisiert. Verfügbarkeit, Nachfrage und rechtliche Nutzbarkeit müssen vor einer Registrierung eigenständig geprüft werden. Öffentliche Quellen: Hacker News API · GitHub Search API · Algolia Hacker News Search.
